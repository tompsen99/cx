# 纱线等级查询系统

这是一个简单的纱线等级查询系统，用于根据长度和细度参数判断纱线等级。

## 功能特点

1. 输入查询
   - 用户可以输入长度(mm)和细度(μm)
   - 系统自动判断对应的等级
   - 实时显示查询结果

2. 等级对照表
   - 可查看完整的等级对照表
   - 需要输入密码(1999)访问
   - 表格以响应式方式显示

## 技术实现

- 纯前端实现，无需后端服务
- 使用 HTML5 + CSS3 + JavaScript
- 响应式设计，适配各种设备
- 数据存储在 JavaScript 对象中

## 使用说明

1. 打开 index.html 即可使用
2. 在输入框中输入长度和细度数值
3. 点击"查询等级"按钮获取结果
4. 点击"查看完整对照表"并输入密码可查看所有等级规则

## 注意事项

- 输入数值必须为有效数字
- 密码为: 1999
- 建议使用现代浏览器访问
